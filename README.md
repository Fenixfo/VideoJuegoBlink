Blink es un videojuego de **plataformas** compuesto por **10 niveles**, desarrollado en el motor **Unity** como parte del semillero de investigación **Makers**, dirigido por el docente **Omar Álvarez**. El proyecto tuvo como propósito afianzar el entorno de desarrollo de Unity y abrir camino para futuros desarrollos estudiantiles de videojuegos.

> "Toma la vida por las uvas, transforma esa mueca en sonrisa" — Los Pitufos

---

## 📖 Sobre el proyecto

Este proyecto documenta el proceso completo de creación de un videojuego desde cero: su estructura, el código utilizado y el diseño de cada escena, hasta llegar a un resultado final jugable. El desarrollo buscó dar a conocer el potencial del entorno de Unity y aprovechar el videojuego como una herramienta práctica para fortalecer conocimientos de lógica y programación.

## 🛠️ Tecnologías utilizadas

- [Unity](https://unity.com/) (motor de videojuego)
- C#
- Assets de la [Unity Asset Store](https://assetstore.unity.com/)

## ▶️ Cómo jugar

1. Descarga el archivo [`Ejecutable.zip`](./Ejecutable.zip).
2. Descomprime el archivo en tu equipo.
3. Ejecuta `Blink Game.exe`.
4. ¡Disfruta del juego! 🎉

> Compatible con Windows.
